Synthetic datasets for geometric smoothing

For the complete task and function catalog, see Finding your way around geosmooth.

geosmooth represents a synthetic dataset as four serializable components: geometry, sampling, truth, and response. synthetic.spec() combines those components without drawing data. materialize.synthetic() performs all random work under an explicit seed and RNG policy and returns a validated synthetic_dataset.

library(geosmooth)

circle.spec <- synthetic.spec(
  geometry = dgraphs::synthetic.circle(radius = 1, ambient.dim = 2),
  sampling = dgraphs::synthetic.sampling.grid.interval(
    0, 2 * pi, endpoints = "exclude.lower"),
  truth = synthetic.truth.polynomial(c(b0 = 0)),
  response = synthetic.response.gaussian(sd = 0.05)
)
circle.data <- materialize.synthetic(circle.spec, n = 80, seed = 2026)
circle.data

The circle has one latent coordinate (angle) and two observed coordinates (the embedding). The constant truth is intentional: this recipe isolates response noise around zero, rather than testing recovery of a varying signal.

     main = "Response and truth")

Quadforms use separate intrinsic and ambient dimensions. A flat geometry has no quadratic forms; a paraboloid or saddle supplies one or more symmetric forms.

surface.spec <- synthetic.spec(
  geometry = dgraphs::synthetic.quadform(
    intrinsic.dim = 2,
    ambient.dim = 5,
    forms = list(diag(c(1, -1))),
    frame = "random.orthonormal"
  ),
  sampling = dgraphs::synthetic.sampling.uniform.box(-1, 1),
  truth = synthetic.truth.polynomial(c(b0 = 0, b1 = 1, b22 = -0.5)),
  response = synthetic.response.gaussian(sd = 0.1)
)
surface.data <- materialize.synthetic(surface.spec, n = 100, seed = 17)

The surface has two latent coordinates and five observed coordinates. The random orthonormal frame embeds the surface in five dimensions. Viewing two coordinates is a projection: points that appear close may be separated in coordinates omitted from the display.

plot(surface.data, view = "geometry", color = "truth", main = "Projected surface")

Two-coordinate projection of a surface embedded in five dimensions. Point colors indicate the known, nonconstant conditional mean; the key uses its actual numerical range.

Maintained benchmark recipes are discoverable through synthetic.registry.ids(). G1–G7 remain compatibility identifiers; the S01–S16 shape identifiers and V1–V3 sampling/noise variants preserve the shared SSRHE regression suite. For example, S01.V1 means two separated narrow equal signal peaks with uniform sampling and Gaussian response noise. G1 is an ambient polynomial example; G2 is a polynomial on a flat embedded geometry. Ordinary datasets bind their full specification hash into dataset.id.

ids <- c("G1", "G2", "S01.V1")
do.call(rbind, lapply(ids, function(id) {
  spec <- synthetic.registry.spec(id)
  data.frame(id, geometry = spec$geometry.spec$family,
             truth = spec$truth.spec$parameters$estimand)
}))
#>       id geometry
#> 1     G1 quadform
#> 2     G2 quadform
#> 3 S01.V1 quadform
#>                                                               truth
#> 1                                       Polynomial conditional mean
#> 2                                       Polynomial conditional mean
#> 3 Gaussian-mixture signal normalized by its realized design maximum
registered <- synthetic.registry.spec("S01.V1")
registered.data <- materialize.synthetic(
  registered, n = 160,
  seed = synthetic.registry.seed("S01.V1", replicate = 1),
  rng.policy = "legacy"
)
synthetic.dataset.checksum(registered.data)
#> [1] "b157f04855125d66efa3802655da6ba495dd9655ea44becc1076daf76c5c5f5c"

Use rng.policy = "named.stream.v1" for new work. The "legacy" policy exists for frozen scientific parity and pins historical RNG behavior. Predictor noise, response noise, and finite-design truth normalization are distinct contracts; they should not be substituted for one another.
