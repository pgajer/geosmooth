Context and supported claims

BibTeX metadata
Pawel Gajer (2026). geosmooth: Geometric Methods for Nonparametric Regression and Density Estimation. R package source, version 0.1.0, GitHub. Commit 9af73498f6e56c9ad9caf9d3b30b169d94eb8de2. Metadata checked against DESCRIPTION.
Source and evidence
Pinned source tree. Locally inspected files:
  • R/malps.R: fit.malps documentation distinguishes support.metric from coordinate.method, defines averaging, lists refit/tuning paths, and defers graph-geodesic new-point prediction. Its binary-response note states that fitted values are not clipped to [0,1].
  • R/local_likelihood.R: Bernoulli branch uses local logistic likelihood; documented support choices and public signature are coordinate-based, without a graph argument. This does not establish a graph-geodesic Bernoulli fitter.
  • R/metric_graph_lowpass.R: compute.filter.weights.matrix gives heat and Tikhonov multipliers; fit.metric.graph.lowpass uses the retained eigenbasis and GCV; .validate.metric.graph.lowpass.response rejects missing values.
  • R/graph_trend_filtering.R: recursive orders 0–2, unit/weighted conventions, experimental path family, and genlasso solver call are explicit.
  • R/harmonic_smoother.R: perform.harmonic.smoothing fixes the boundary of a specified region and updates its interior; this is not a general label-mask contract.
  • NAMESPACE: inspected the full export list against the package method map; no complete public local-covariance or field-association interface is exposed. Development specifications are not counted as public API.
  • R/lpl_tf.R: lpl.tf.operator defines self-excluded residual rows, rank-deficiency policy and output metadata; predict.lpl_tf rejects non-NULL newdata; fitting calls genlasso::genlasso.
  • R/slpl_tf.R: slpl.tf.operator constructs and returns A_LPL and C_sync with row metadata and diagnostics.
  • R/ssrhe_hessian_energy.R: constructor documents the R/C++ port of prior Hessian-energy behavior, operator and energy matrices, diagnostics, and support choices. fit.ssrhe.hessian.regression documents its weighted linear system and missing-response conversion. derivative.order = 3 is experimental. Multiplying Kim et al.'s normalized criterion by the labeled sample count yields the penalty-scaling correspondence in the review.
  • README.md: method map and graph-dependency boundary; corroborated by the source files above and DESCRIPTION.
Local links refer to the working tree; the pinned URL defines the audited version if subsequent source changes occur.
Verifier notes
Codex, 2026-09-02: read the documented definitions and relevant implementation paths. No experiment was rerun. This verification is not a proof of numerical correctness, a novelty determination, or a check of the original methodological literature. Broader claims remain open in the draft's evidence agenda.
