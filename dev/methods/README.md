# Method contracts

Keep binding implementation and test specifications in this directory.
Scientific exposition and study reports belong in `../geosmooth_manuscripts/`
(relative to the package root), following `DOCUMENT_LOCATIONS.md`.
Agent-only reviews, audit evidence, runs, handoffs, and status reports belong
under `~/.codex/private/geosmooth/`; they are not package build inputs.
See `dev/README.md` for the source and build map.
