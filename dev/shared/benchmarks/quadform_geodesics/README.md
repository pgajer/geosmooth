# Quadratic-surface tools moved

Maintained geometry reference/comparison tools now live in dgraphs at
`dev/shared/benchmarks/quadform_geodesics/`. The historical manuscript sources
and `native/package_profile/` remain here. That profiler was already
incompatible with the instrumented solver before migration; it is not a
supported benchmark of the relocated implementation. No timing claims were
regenerated as part of this move.
